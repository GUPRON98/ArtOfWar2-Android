## ⚡ Fitur Utama

- 🕹️ **Direct Screen Touch (Sentuhan Layar Penuh)**:
  - Mengendalikan unit, membangun markas, mengatur formasi, dan navigasi radar minimap langsung melalui sentuhan layar tanpa d-pad virtual yang memakan tempat.
- ⚡ **Tombol Floating Bertema Militer Taktis**:
  - **`⚡ CHEAT` (Kiri Atas)**: Plakat Tactical Red Lacquer berbingkai ganda Amber Gold (`#F39C12`) dengan paku keling tempur untuk membuka dialog cheat instan (Kredit +10.000 / +50.000, God Mode, Full Map, Auto Win).
  - **`⚙️ OPSI` (Kanan Atas)**: Plakat Steel Armor / Dark Camo berbingkai Tactical Gold (`#F1C40F`) untuk mengatur mode layar, orientasi, FPS lock, dan keluar game.
- 📺 **Orientasi Portrait & Landscape Fleksibel**:
  - **Portrait (Bawaan)**: Tampilan tegak layar penuh (*Fullscreen Stretch*) yang pas di genggaman satu tangan.
  - **Landscape**: Mode layar lebar untuk jangkauan peta tempur yang lebih luas.
  - **Sensor Otomatis**: Menyesuaikan orientasi perangkat secara instan.
- 🎯 **Pacing FPS & Framerate Limiter**:
  - Pilihan kecepatan render real-time: **15 FPS (Kecepatan Asli J2ME)**, **20 FPS (Halus)**, **25 FPS**, **30 FPS (Turbo RTS)**.
- 👆 **Smart Touch Softkey Navigation**:
  - Pojok kiri bawah layar untuk LSK (Menu Konstruksi).
  - Pojok kanan bawah layar untuk RSK (Batal / Peta Taktis / Pause).
  - Area tengah bawah untuk konfirmasi prompt misi.
